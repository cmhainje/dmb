# dmb/agora

This directory contains code for setting up and performing simulations of the [AGORA isolated disk galaxy](https://arxiv.org/pdf/1610.03066).
The initial conditions were [made public](https://www.dropbox.com/scl/fo/70s6ce0zhiu0ig61cyyd4/ANxOuHlr7yMM-AjjLsBSwQs?rlkey=j45u9nchnml1azlg9oxbv3yvm&e=1); we have here translated the "LOW" resolution ICs into the HDF5 format used by GADGET/GIZMO.
